STEP 1: Update AndroidManifest.xml (2 minutes)
================================================================================

FILE: AndroidManifest.xml

FIND THIS:
  <manifest xmlns:android="http://schemas.android.com/apk/res/android"
      package="com.nipuna.cyberai">

AFTER IT, ADD THESE PERMISSIONS:

  <uses-permission android:name="android.permission.READ_EXTERNAL_STORAGE" />
  <uses-permission android:name="android.permission.WRITE_EXTERNAL_STORAGE" />
  <uses-permission android:name="android.permission.MANAGE_EXTERNAL_STORAGE" />
  <uses-permission android:name="com.termux.permission.RUN_COMMAND" />
  <uses-permission android:name="android.permission.INTERNET" />
  <uses-permission android:name="android.permission.ACCESS_SUPERUSER" />

✅ SAVE and CLOSE

================================================================================
STEP 2: Add FullAccessUtils.kt (2 minutes)
================================================================================

LOCATION: app/src/main/java/com/nipuna/cyberai/

ACTION:
  1. Right-click on: com.nipuna.cyberai package
  2. Select: New → Kotlin Class
  3. Name it: FullAccessUtils
  4. Delete all content
  5. Copy entire content from: KOTLIN/FullAccessUtils.kt
  6. Paste into new file

✅ SAVE and CLOSE

================================================================================
STEP 5: Build & Test (2 minutes)
================================================================================

BUILD:
  1. Android Studio → Build menu
  2. Click: Clean Project
     (Wait for completion)
  
  3. Android Studio → Build menu
  4. Click: Rebuild Project
     (Wait for completion)

RUN:
  1. Click green Play button (or Run → Run 'app')
  2. Select your device/emulator
  3. Wait for app to start

GRANT PERMISSIONS:
  1. App will ask for storage permissions
  2. Click: Allow/Grant
  3. App now has full access!

TEST:
  1. In app, go to Terminal tab
  2. Type: $ access info
  
  SHOULD SEE:
    🔐 Access Status:
      Storage: ✅ Full Access
      Termux: ✅ Available

✅ DONE! Full access working!
