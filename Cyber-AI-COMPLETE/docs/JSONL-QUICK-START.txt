================================================================================
KOTLIN METHODS (Android Side)
================================================================================

@JavascriptInterface fun loadJSONL(tk, filePath)
- Load and parse JSONL file
- Usage: Android.loadJSONL(token, uri)

@JavascriptInterface fun filterJSONL(tk, column, value)
- Filter rows by column
- Usage: Android.filterJSONL(token, "age", "35")

@JavascriptInterface fun getJSONLStats(tk, column)
- Get min/max/avg/unique for column
- Usage: Android.getJSONLStats(token, "age")

@JavascriptInterface fun exportJSONLToCSV(tk)
- Export to CSV file
- Saves to: ~/workspace/out/export_*.csv
- Usage: Android.exportJSONLToCSV(token)

@JavascriptInterface fun queryJSONL(tk, query)
- Simple SQL-like queries
- Usage: Android.queryJSONL(token, "SELECT name WHERE age>25")

@JavascriptInterface fun getJSONLAsJSON(tk)
- Get data as JSON array
- Usage: Android.getJSONLAsJSON(token)

================================================================================
TROUBLESHOOTING
================================================================================

File won't load?
→ Check .jsonl format (one JSON per line)
→ Each line must be valid JSON

No columns showing?
→ JSON objects must have consistent keys
→ Check first 3 lines

Export empty?
→ Load JSONL first: jsonl info
→ Then export: jsonl export

Slow on large files?
→ Normal for 50MB+ files
→ Filter first, then export
