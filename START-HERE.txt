  ❌ System files without root
  → But CAN use root commands via shell!

⚠️ IMPORTANT NOTES
================================================================================

1. PERMISSIONS
   App will ask for storage permissions on first run
   You must grant them (permission dialog)

2. ROOTED DEVICE RECOMMENDED
   Works without root for basic storage
   Works better with root for all operations

3. TERMUX OPTIONAL
   Termux must be installed for Termux features
   APIs work anyway (returns empty if not installed)

4. BACKUP YOUR CODE
   Always backup MainActivity.kt before editing
   Integration is simple but important

5. NO GRADLE CHANGES
   Don't need to modify build.gradle.kts
   Don't need to change project structure
